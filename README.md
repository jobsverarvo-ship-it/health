# 건강한통

매일 아침 건강 한 통.

60세 이상을 위한 매일 건강 정보 알림 서비스의 웹사이트와 회원 서버입니다.

- 무료: 나라 기관(식약처·기상청 등) 공식 자료로 만든 건강 정보를 매일 아침 카카오톡(또는 문자)으로 한 가지씩 발송, 내 건강정보함
- 멤버십 (월 3,900원): 건강 맞춤 상담 하루 3번, 관심 건강에 맞춘 정보, 주간 건강 특집, 약·영양제 궁합 확인, 나라 혜택 알림

## 지금 되는 것

- 휴대폰 번호 + 문자 인증번호로 가입·로그인 (비밀번호 없음)
- 카카오 로그인 (카카오 키를 넣기 전에는 개발용 연습 화면)
- 가입: 이름 → 관심 건강 → 받는 방법·시간 → 동의. 이미 가입한 분은 같은 방법으로 들어오면 바로 로그인
- 내 건강정보함: 오늘의 정보, 지난 정보(검색·주제별), 저장한 정보, 내 설정(받는 시간·방법, 관심 건강, 잠시 멈추기, 로그아웃, 탈퇴)
- 로그인하지 않은 분이 건강정보함이나 멤버십에 들어오면 로그인 화면을 보여 줌
- 회원 정보와 저장한 정보는 서버에 저장. 다른 기기에서 로그인해도 그대로 보임

**아직 안 되는 것:** 멤버십 결제(화면만 있음), 매일 아침 실제 발송, 콘텐츠 엔진 연결. 아래 ‘실제 서비스 전에 할 일’ 참고.

## 내 컴퓨터에서 실행하기

파이썬 3.10 이상이 필요합니다. 이 폴더(`health`)에서 PowerShell을 열고:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r server/requirements.txt
python -m uvicorn server.main:app --port 8000
```

브라우저에서 http://localhost:8000 을 여세요. 끌 때는 서버 창에서 `Ctrl + C`.

설정 파일 없이 켜면 **개발용**으로 돌아갑니다.

- 인증 문자는 실제로 보내지 않고, **서버 창에 인증번호 6자리가 찍힙니다.** 그 숫자를 화면에 넣으면 됩니다.
- ‘카카오로 시작하기’를 누르면 실제 카카오 대신 **연습 화면**이 열립니다. 이름을 적으면 카카오로 가입한 것처럼 이어집니다.
- 회원 정보는 `server/data/app.db` 파일에 저장됩니다. 지우면 처음 상태로 돌아갑니다.

GitHub Pages(`https://jobsverarvo-ship-it.github.io/health/`)는 파일만 보여 주는 곳이라 서버가 없습니다. 그곳에서는 첫 화면은 그대로 보이고, 가입·로그인 화면에는 ‘미리보기라 가입할 수 없다’는 안내가 나옵니다.

### 자동 시험

```powershell
pip install -r server/requirements-dev.txt
python -m pytest server/tests -q
```

가입, 로그인, 틀린 인증번호 5번이면 잠김, 1분 안 재발송 막기, 인증번호 시간 초과, 카카오 연습 로그인, 다른 사이트에서 보낸 요청 막기, 설정 바꾸기, 저장, 탈퇴 등 24가지를 확인합니다.

## 진짜 카카오 · 진짜 문자로 가입해 보기 (키 준비)

`server/.env` 에 키를 넣으면 내 컴퓨터에서도 **실제 카카오 로그인**과 **실제 문자 인증**이 됩니다. (`server/.env` 가 없으면 `server/.env.example` 을 복사해 만드세요.)
**`.env` 는 GitHub에 올라가지 않으니 키는 여기에만 적으세요.** 채팅이나 코드에 키를 붙여 넣지 마세요.

### 1. 카카오 로그인 — Kakao Developers (무료)

1. https://developers.kakao.com 에 카카오 계정으로 로그인하고 **애플리케이션을 추가**합니다. (앱 이름: 건강한통)
2. **[앱] > [플랫폼 키] > [REST API 키]** 에서
   - REST API 키 → `KAKAO_REST_API_KEY`
   - **[클라이언트 시크릿]** 값 → `KAKAO_CLIENT_SECRET` (새 앱은 기본으로 켜져 있어서 꼭 필요합니다)
   - **리다이렉트 URI** 에 아래 주소를 글자 하나 틀리지 않게 등록
     - 내 컴퓨터: `http://localhost:8000/api/auth/kakao/callback`
     - 실제 서비스: `https://(사이트 주소)/api/auth/kakao/callback`
3. **[카카오 로그인] > [사용 설정] > [상태]** 를 **ON** 으로 바꿉니다.
4. **[카카오 로그인] > [동의항목]** 에서 **닉네임**을 켭니다. (가입 화면에 이름을 미리 채우는 데만 씁니다. 전화번호·이메일은 받지 않습니다.)

콘솔 메뉴 이름은 카카오가 바꿀 수 있으니, 화면이 다르면 카카오 개발자 문서 ‘카카오 로그인 > REST API’ 를 따르세요. 키를 넣으면 연습 화면은 자동으로 닫힙니다.

### 2. 문자 인증 — 솔라피(Solapi) (문자 한 통마다 요금)

1. https://solapi.com 에 가입하고 본인인증을 합니다.
2. **발신번호 등록**: 문자를 보내는 번호를 미리 등록해야 합니다(전기통신사업법). 본인 휴대폰 번호는 본인인증으로 바로 등록할 수 있습니다. → `SMS_FROM`
3. **잔액 충전**: 잔액이 있어야 문자가 나갑니다.
4. **API 키 발급**: API Key, API Secret → `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`
5. `SMS_PROVIDER=solapi` 로 바꿉니다.

서버는 솔라피 **공식 파이썬 라이브러리(`solapi`)** 로 보냅니다. 다른 문자 업체를 쓰려면 `server/sms.py` 에 같은 모양의 `send(to, text)` 를 하나 더 만들면 됩니다.

### 3. 키 확인 → 서버 다시 켜기 → 가입

```powershell
pip install -r server/requirements.txt
python -m server.check
python -m server.check --send 01012345678
python -m uvicorn server.main:app --port 8000
```

- `python -m server.check` : 카카오 키·시크릿, 솔라피 키와 잔액을 확인합니다. 틀린 곳이 있으면 무엇을 고칠지 알려 줍니다. (문자는 보내지 않음)
- `--send 내번호` : 그 번호로 시험 문자 한 통을 실제로 보냅니다.
- `.env` 를 바꾼 뒤에는 **서버를 껐다 켜야** 적용됩니다.
- 그다음 **http://localhost:8000** 을 열고 ‘휴대폰 번호로 시작하기’ 또는 ‘카카오로 시작하기’로 가입해 보세요. 인증번호는 휴대폰 문자로 옵니다.

**휴대폰 브라우저로 사이트를 열고 싶다면:** `localhost` 는 이 컴퓨터 안에서만 열립니다. 휴대폰에서 사이트까지 열려면 서버를 인터넷에 올려야 합니다(아래 ‘올릴 곳’). 그때는 카카오 리다이렉트 URI 에 그 주소도 함께 등록하세요.

### 4. 실제 서비스 설정값

| 항목 | 값 |
|---|---|
| `APP_ENV` | `production` |
| `PUBLIC_URL` | `https://` 로 시작하는 실제 주소 |
| `APP_SECRET` | `python -c "import secrets; print(secrets.token_urlsafe(48))"` 로 만든 값 |

`production` 에서는 서버가 스스로 확인합니다. 비밀값이 없거나, 주소가 https가 아니거나, 문자를 실제로 안 보내는 설정이면 **켜지지 않습니다.** (인증번호가 로그에만 찍힌 채 서비스되는 사고를 막기 위해서입니다.)

### 5. 올릴 곳 (호스팅)

이 서버는 파이썬 프로그램이 계속 켜져 있어야 해서 GitHub Pages로는 안 되고, 서버를 돌려 주는 곳이 필요합니다. 예: Render, Railway, Fly.io, 또는 국내 클라우드(네이버 클라우드, AWS 서울 등).

- 실행 명령: `python -m uvicorn server.main:app --host 0.0.0.0 --port $PORT`
- 회원 정보 파일(`server/data/app.db`)이 **재시작해도 지워지지 않는 디스크**에 있어야 합니다. 서버를 여러 대로 늘릴 때는 PostgreSQL 같은 데이터베이스로 옮기세요.
- 회원 정보를 다루므로 정식 오픈 전에 개인정보처리방침과 보관·파기 기준을 정하세요.

## 보안에서 신경 쓴 점

- 비밀번호를 받지 않습니다. 로그인은 문자 인증번호 또는 카카오.
- 인증번호는 원문을 저장하지 않고(HMAC), 5분 뒤 만료, 5번 틀리면 잠김, 1분에 한 번·하루 10번까지만 발송, 같은 곳에서 1시간 20번까지.
- 로그인 상태는 자바스크립트가 읽을 수 없는 쿠키(HttpOnly, SameSite=Lax, https에서는 Secure)에 담고, 서버에는 토큰의 해시만 저장. 로그인할 때마다 새 토큰으로 바꿈.
- 다른 사이트에서 몰래 보내는 요청을 막기 위해 모든 변경 요청에 전용 헤더와 출처 확인.
- 카카오 로그인은 `state` 값으로 위조를 막고, 로그인 뒤 이동할 주소는 정해 둔 페이지로만 허용.
- 탈퇴하면 회원 정보, 동의 기록, 저장한 정보, 로그인 기록을 함께 지움.
- 서버 설정 파일·회원 정보 파일은 웹에서 열리지 않음(정해 둔 페이지와 `assets` 만 공개).

### 서버 주소(API)

| 주소 | 하는 일 |
|---|---|
| `GET /api/session` | 로그인 여부 (안 했으면 `user: null`) |
| `POST /api/auth/phone/start` | 인증번호 보내기 |
| `POST /api/auth/phone/verify` | 인증번호 확인 → 로그인 또는 가입 이어서 |
| `GET /api/auth/kakao/start` | 카카오 로그인 시작 |
| `GET /api/auth/kakao/callback` | 카카오가 돌려보내는 곳 |
| `GET /api/auth/pending` | 가입 중인 정보(카카오 이름 등) |
| `POST /api/auth/signup` | 가입 마치기 |
| `POST /api/auth/logout` | 로그아웃 |
| `GET` · `PATCH` · `DELETE /api/me` | 내 정보 보기 · 바꾸기 · 탈퇴 |
| `GET /api/tips` | 건강정보함 정보 |
| `GET /api/me/saved`, `PUT` · `DELETE /api/me/saved/{id}` | 저장한 정보 |

개발용으로 켜면 http://localhost:8000/api/docs 에서 모든 주소를 직접 눌러 볼 수 있습니다.

## 어르신을 위한 배려

- 기본 글자 18px. 오른쪽 위 ‘글자 크기’ 버튼을 누르면 보통 / 크게 / 더 크게를 실제 크기 견본을 보며 고를 수 있고, 화면 전체 글씨가 커짐
- 비밀번호 없는 가입, 가입과 로그인을 같은 버튼으로
- 가입은 한 화면에 질문 하나, 큰 버튼, 진행 단계 표시, 이전으로 돌아가기
- 오류는 무엇을 하면 되는지까지 쉬운 말로 (예: “번호가 맞지 않아요. 4번 더 넣어 보실 수 있어요.”)
- ‘소리로 듣기’ (브라우저 음성 읽기), 저장, 가족에게 보내기
- 카카오톡이 없으면 휴대폰 번호로 가입하고 문자로 받기
