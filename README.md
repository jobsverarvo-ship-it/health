# 건강한통

매일 아침 건강 한 통.

60세 이상을 위한 매일 건강 정보 알림 서비스의 웹사이트 시안입니다.

- 무료: 약사가 확인한 건강 정보를 매일 아침 8시 카카오톡으로 한 가지씩 발송
- 멤버십 (월 3,900원): 건강 맞춤 상담 하루 3번, 내 질환·약에 맞춘 심화 정보, 주간 건강 특집, 약·영양제 궁합 확인, 나라 혜택 알림

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 페이지 (HTML, CSS, JS가 한 파일에 들어 있음) |

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 컴퓨터와 휴대폰 화면 크기에 맞춰 배치가 바뀝니다.

## 페이지 구성

1. 첫 화면: 서비스 한 줄 소개와 카카오톡 메시지 예시
2. 건강한통이 다른 점: 흔히 보는 건강 정보와 비교
3. 보내 드리는 정보 6가지 주제
4. 이번 주 건강 정보 미리 보기 (요일 선택)
5. 시작하는 방법 3단계
6. 멤버십 요금 비교와 결제 신청 창
7. 건강 상담 대화 예시
8. 약속, 자주 묻는 질문, 하단 안내

어르신 사용성을 위해 기본 글자를 18px로 잡았고, 상단 "글자 크기" 버튼(보통 / 크게 / 더 크게)으로 화면 전체 글씨를 키울 수 있습니다.
